Transformers, Attention Mechanism & How GPT Learns Language
Overview

This repository contains learning notes and presentation slides explaining the core concepts behind Large Language Models (LLMs) such as GPT, Claude, Gemini, and Llama.

The content is designed for beginners who want to understand how modern AI language models work.

Transformers are the foundation of modern LLMs.
Attention helps models focus on relevant information.
Self-Attention enables context understanding.
QKV powers the attention mechanism.
GPT learns by predicting the next token repeatedly.
